# 🎓 CampusConnect – Student Portal

![HTML5](https://img.shields.io/badge/HTML-5-orange) ![CSS3](https://img.shields.io/badge/CSS-3-blue) ![Bootstrap](https://img.shields.io/badge/Bootstrap-5.3.3-purple) ![Status](https://img.shields.io/badge/Status-Frontend%20Prototype-green)

## About
CampusConnect is an academic web development project that brings student information, courses, notices and teacher feedback together in a responsive interface.

## Problem statement and objectives
Students often need to consult multiple sources for academic updates. CampusConnect demonstrates a centralized portal, simple navigation, responsive layouts and UI/UX prototyping.

## Features
| Module | Function |
| --- | --- |
| Dashboard | Sample attendance, courses, assignments and notices |
| Courses | Six semester subject cards |
| Notices | Academic, department, event and library announcements |
| Feedback | Teacher, subject, rating and comment form |
| Profile | Sample student information |
| Login | Demonstration form with browser validation |

## Technology stack
HTML5, CSS3, Bootstrap 5.3.3 (CDN), Bootstrap JavaScript bundle for the mobile navbar, and Figma for prototyping. CSS fragment navigation uses :target and :has().

## Run locally
1. Clone: `git clone https://github.com/santushtgoyal007/CAMPUS-CONNECT-PORTAL.git`
2. Open index.html in a modern browser or use VS Code Live Server.
3. Internet access is needed for Bootstrap CDN assets.

## Limitations
Static frontend demonstration with sample data. Login does not authenticate users; feedback is not stored; no backend or database. Do not enter real passwords. The security standard mentioned in the interface is a reference, not a certification.

## Future scope
- Backend and database integration
- Secure authentication and role-based access
- Live attendance and notice updates
- Persistent feedback and assignment tracking
